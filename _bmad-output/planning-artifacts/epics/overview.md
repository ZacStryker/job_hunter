# Overview

This document provides the complete epic and story breakdown for HITLOBSTER (originally "Job Hunt Dashboard"), decomposing the requirements from the PRD, UX Design, and Architecture into implementable stories.

The breakdown spans the original foundation (Epics 1–8), the multi-user/hosting expansion (Epics 24–27), and the post-launch evolution (Epics 28–44 + implementation specs). Some original epics were later superseded — notably Epic 2 (Google Sheets sync) by the self-contained Discovery/Analysis pipeline, and Epic 7's n8n webhook callback by direct in-app generation. See `requirements-inventory.md` for the current requirement set and the FR → epic/spec coverage map.
