## What Didn't Go Well

### Architecture distillate contained wrong score thresholds
`architecture-distillate.md` lists FitScoreBadge thresholds as `<60 red / 60–79 yellow / ≥80 green`. The correct values per Epic 3 AC are `<50 / 50–74 / ≥75`. This discrepancy was caught at implementation time — it should not have been an open question. `ScoreBadge` is reused in the Epic 4 drawer; the distillate must be corrected before Story 4.1 is created.

### Spec document conflicts (UX spec vs. architecture)
- `components/jobs/` (UX spec) vs. `components/pipeline/` (architecture + project context) — resolved correctly, but created avoidable uncertainty.
- Local-state view switching (UX spec) vs. TanStack Router routing (architecture) — resolved correctly, but Story 3.4 explicitly noted the conflict.
These conflicts indicate the UX spec was not updated when architectural decisions were finalized.

### `get-refresh-token.ts` unresolved flag
Story 3.1 code review flagged `get-refresh-token.ts` as untracked and recommended confirming it is in `.gitignore` before any commit. This was recorded as `[Flag][Out-of-scope]` but was never confirmed resolved. This is a potential credentials-in-repo issue that should be verified before Epic 4 begins.

### EmptyState sync error not surfaced
The original Story 3.4 implementation gave no user feedback when `syncMutation.isError` was true — the button silently reset to "Sync" after failure. This was caught in code review and deferred. It was a gap in the story AC, not a dev error: the AC described the success path but not the error path for the sync button.

## Patterns to Carry Forward

- **Always use epic AC as the implementation source of truth** when it conflicts with other documents.
- **Explicit Out-of-Scope list** in every story's dev notes.
- **Deferred items with file + line number** in `deferred-work.md`.
- **Raw `<table>` element** (not shadcn `<Table>` wrapper) for any table with a sticky header inside an `overflow-auto` container.
- **`/home/zac/.bun/bin/bun`** — not `bun` — for all CLI commands in this project.
- **`process.env.DB_PATH = ':memory:'` at line 1** before any imports in test files touching the DB.
- **Column defs outside the component function** to prevent recreation on every render.
